# UnifyVault Manifesto — The Core Principles

## 1. Trust by Verification, Not Claims

We build protocols where security is mathematically verified on-chain, not promised in marketing materials. Every line of code, storage slot, and permission hierarchy is public and deterministic.

## 2. Non-Proxy Immutability

Upgradable proxies introduce backdoor vulnerabilities and centralized key risks. UnifyVault V2 enforces an immutable non-proxy architecture. Once deployed, the smart contract logic is locked forever.

## 3. Zero Private Key Server Architecture

The protocol operates 100% autonomously without backend servers, relayer daemons, or private keys. The blockchain itself is the single source of truth.

## 4. Trust-Minimized Governance

Administrative power is strictly bounded by a 4-of-7 hardware multisig and a 48-hour mandatory execution timelock. Governance cannot steal funds or mutate asset balances.

## 5. Non-Custodial Sovereignty

Users retain full control of their assets at all times. Redemptions are guaranteed directly by the smart contract code without administrative approval.
