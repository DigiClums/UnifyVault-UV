# Contract ABIs

This directory contains the Application Binary Interfaces (ABI) for all core smart contracts in UnifyVault V2:

- `UnifyVaultController.json`
- `CustodyVault.json`
- `Treasury.json`
- `StrategyManager.json`
- `FeeManager.json`
- `OracleManager.json`
- `ProtocolDirectory.json`
- `UnifyVaultTimelock.json`
- `UVBTCETHToken.json`

Full ABI tables and signatures are locked in [`ABI_LOCK.md`](file:///var/www/UnifyVault-UV/ABI_LOCK.md).
