# UnifyVault V2 — Public Community Review Guidelines

## Overview

We welcome community review, feedback, issue reports, and integration suggestions for UnifyVault V2 prior to production mainnet launch.

## How to Participate

1. **GitHub Discussions**: Visit our repository GitHub Discussions tab:
   - **Category: Security & Audits** — For security feedback and threat analysis.
   - **Category: Integrations & Ideas** — For dApp, wallet, and protocol integration proposals.
   - **Category: Public Testnet Feedback** — For reporting issues encountered during Base Sepolia testing.

2. **Issue Reporting**:
   - For non-critical bug reports or UI issues: Open a GitHub Issue using our standard template.
   - For security vulnerabilities: Follow our [`BUG_BOUNTY.md`](file:///var/www/UnifyVault-UV/docs/BUG_BOUNTY.md) instructions and email **`security@unifyvault.io`**.

3. **Public Testnet Testing Flows**:
   - Testnet Token Faucet: Get Base Sepolia USDC/WETH.
   - Execute: Deposit, Redeem, Rebalance, Governance, Emergency Pause, Resume.
