# Scoring Engine — Early Signal Strength (0 - 100)

The scoring engine implements an explainable, deterministic mathematical model.

| Category        | Max Points | Evaluation Factors                                                                           |
| :-------------- | :--------- | :------------------------------------------------------------------------------------------- |
| **Development** | **25**     | Language (Solidity/Rust/Cairo), Commit velocity, Contributor decentralization, Contract code |
| **On-Chain**    | **25**     | Verified contract deployments, Bytecode verification, Testnet telemetry                      |
| **Community**   | **15**     | Discord/X links, GitHub stargazers                                                           |
| **Funding**     | **15**     | Verified grants, VC backing, Foundation sponsorship                                          |
| **Product**     | **10**     | Live dApp portal, Technical documentation                                                    |
| **Incentives**  | **10**     | Documented point system, testnet quest program, tokenomics                                   |

Total = 100 points.

Every score snapshot stores structured `explanations` explaining every point added or omitted.
